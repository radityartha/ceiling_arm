reachability_gng — Quick Start

Growing-Neural-Gas reachability/capability clouds for the ceiling workcell, shown live in RViz with MoveIt MotionPlanning. One cloud per arm (arm_1 green, arm_2 orange), nodes colored by manipulability. Table_1 focus; table rotation ±180°, home −90°.

0 · Build once

cd ~/arm_WS/ceiling_arm/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select reachability_gng --symlink-install
source install/setup.bash

# generate the two GNG maps -> /tmp/arm1_model.npz, /tmp/arm2_model.npz
cd ~/arm_WS/ceiling_arm
ros2_ws/src/reachability_gng/build_maps.sh

Adding arm_3/arm_4 later = one line in build_maps.sh + a config YAML.

0b · Tune the cloud (samples & node count)

build_maps.sh reads env vars (defaults N=80000 LAM=60 MAX_NODES=3000 EPOCHS=2 → ~2668 nodes). Node count ≈ N × EPOCHS / LAM.

N=200000 ros2_ws/src/reachability_gng/build_maps.sh   # more FK samples (denser, slower)
LAM=160  ros2_ws/src/reachability_gng/build_maps.sh   # ~1000 nodes (sparser cloud)

Fewer nodes, same coverage: keep N high (samples = covered area) and raise LAM — GNG still spreads the nodes over the whole region, so the cloud just gets sparser, not smaller. Pick LAM ≈ N×EPOCHS / (target nodes) → 110≈1450, 160≈1000, 320≈500. Don't lower N to cut nodes (that shrinks coverage + ragged edge).

Then reload: pkill -9 -f lib/reachability_gng/visualize and relaunch gng_clouds.launch.py / launch_workcell.sh.

A · With Isaac Sim recommended

Robot driven by the Isaac digital twin; plan in RViz, watch it move in Isaac (noVNC: http://<server>:22380/vnc.html).

cd ~/arm_WS/ceiling_arm
./isaac_sim/stop.sh            # clear any old session
./isaac_sim/launch_workcell.sh # default 'gng' mode

Brings up: Isaac bridge → move_group (table_1-only) → both clouds → RViz. table_2 / arm_3 / arm_4 are hidden in both Isaac and RViz. In RViz pick Planning Group table_1_with_arm_1 or table_1_with_arm_2 → Plan → Execute.

Modes:

commandwhat you get
launch_workcell.shtable_1 only + clouds + RViz (default)
launch_workcell.sh fullall 4 arms + 2 tables, RViz
launch_workcell.sh demoall 4 arms, scripted loop (no RViz)
launch_workcell.sh headlessbridge + move_group only

Ctrl-C (or ./isaac_sim/stop.sh) stops everything.

B · Without Isaac (fake hardware)

Pure kinematic: mock controllers, no Isaac, no real arms.

source /opt/ros/humble/setup.bash && source ros2_ws/install/setup.bash
ros2 launch reachability_gng gng_moveit.launch.py

Cloud-only look (sliders, no MoveIt): ros2 launch reachability_gng view_gng.launch.py model_path:=/tmp/arm1_model.npz
