⚠ Why a script and not ros2 launch ... launch_rviz:=true? RViz is on a TimerAction inside the combined launch, but the included kortex/move_group sub-launches starve the launch event loop so the timer never fires and no window appears. The script polls for readiness instead. (launch_rviz defaults to false.)

Troubleshooting
Web page unreachable, node still runningvoice_web_ui.py wraps stdlib http.server with SSL by hand — a connection that never completes the TLS handshake (raw probe, http:// instead of https://) can wedge its single-threaded accept() forever. ss -tlnp | grep 8080 still shows LISTEN but every request times out. Fix: find the PID, kill -9 <pid>, then ros2 run sayai_voice_sim voice_web_ui again — the other 3 nodes don't need restarting.
UI says "finished OK" but arms didn't move / log shows ABORTINGreal_robot_task_server only reports failure if the demo subprocess exits non-zero — check the matching run_*.py ends with sys.exit(main()), not a bare main() call.

click to copy

Replace enp1s0 with your actual Ethernet interface name.
